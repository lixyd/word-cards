# 单词卡 · 图音义英语学习

一张卡片三个信息：**图 → 音 → 义**。1202 个高频具象名词，每词一张配图、一个真人级发音、一个音标，**不带语法、不背拼写**，像小时候认卡片那样认单词。纯前端实现，无需安装、无需联网（打开后全部资源本地加载）。

**在线使用（主入口）**：<https://xiaobaiai.asia/cards/>
**GitHub Pages 镜像**：<https://lixyd.github.io/word-cards/>（本仓库，无返回主页按钮）

## 功能

| 模式 | 说明 |
|---|---|
| **学习新词** | 看图 → 听音 → 翻面见中文，每轮 10 词；点「还不认识」的词当轮末尾再来一遍（错词循环） |
| **复习** | 看图选词 4 选 1，答对升箱、答错回箱，按 **5 分钟 / 1 天 / 3 天 / 7 天 / 15 天** 五级间隔滚动安排 |
| **图库** | 1202 词按 21 个分类网格展示，支持中英文搜索，点任意卡片发音，可当词典用 |

支持深链：`?mode=learn` / `?mode=review` / `?mode=browse`。

学习进度存在浏览器 `localStorage`，只在本机，不上传任何服务器。

## 数据规模

- **1202 词** · 21 分类（动物 / 食物 / 身体 / 交通 / 家具 / 天气 / 乐器…）
- **音标覆盖 1165/1202（97%）**，来自 CMUdict + 自研 ARPAbet→IPA 转换
- **每词都带英文例句 + 中文翻译**
- **发音 1202/1202**，本机 Kokoro-82M（`af_heart` 美音女声）离线合成，静音修剪后均值 0.59 秒
- **发音质检**：Whisper 回环识别 + 例句语境复测（95.8% 正确）+ 词典真人录音对照，详见下文「质量验收」

## 技术实现

- 纯 HTML / CSS / JS 单页，**零依赖、零后端、零构建**（仓库可直接当静态站点跑）
- 图片：Google Noto Emoji 2D（Apache 2.0）为主 + OpenMoji 等 231 张兜底图（已转 512px WebP）
- 发音：Kokoro-82M 本地 TTS → AAC 64k，全量离线生成
- 复习算法：自研五级 Leitner 盒，进度存 localStorage

## 质量验收（自动化流水线）

1. **静音修剪**：RMS 能量法裁掉首尾静音，单条均值 1.49s → 0.59s，99% 落在 0.41–0.90s
2. **识别回环**：Whisper（large-v3-turbo）把 1202 条音频「听写」回文字逐一比对，随机抽检 10/10 一致
3. **例句复测**：把可疑词放进完整例句重新合成再识别，95.8% 正确 —— 排除孤立短词的识别幻觉
4. **真人对照**：每词附词典真人录音，可随时 A/B 试听

## 本地运行

仓库本身就是站点，任选一种：

```bash
# Python
python3 -m http.server 8080
# 或 Node
npx serve .
```

然后打开 <http://localhost:8080>。直接双击 `index.html` 也可以（Chrome 下音频与图片均可正常加载）。

## 目录结构

```
index.html          应用入口（学习 / 复习 / 图库三模式）
words.json          1202 词数据（释义/词性/音标/例句/分类/图源）
img-noto/           Noto Emoji 2D 配图（主图源）
assets/             OpenMoji 等兜底配图（512px WebP）
audio-kokoro-trim/  主发音（Kokoro af_heart，已消静音）
audio/              词典真人录音（兜底音源）
```
